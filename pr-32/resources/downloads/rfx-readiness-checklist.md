# RFx Readiness Checklist

Use this checklist before committing response effort.

## Opportunity identity
- [ ] Buyer / issuer identified
- [ ] RFx / solicitation reference recorded
- [ ] Due date and submission method recorded
- [ ] Performance geography understood

## Requirements
- [ ] Mandatory requirements separated from preferred requirements
- [ ] Deliverables identified
- [ ] Evaluation factors recorded when published
- [ ] Open questions documented

## Organization fit
- [ ] Relevant capabilities identified
- [ ] Supporting evidence / credentials available where required
- [ ] Delivery capacity reviewed
- [ ] Geography / service area fit reviewed

## Gaps and partners
- [ ] Disqualifying gaps identified
- [ ] Solvable gaps identified
- [ ] Teaming / supplier / resource needs identified
- [ ] Potential partner criteria documented

## Pursuit ownership
- [ ] One accountable pursuit owner named
- [ ] Internal contributors identified
- [ ] Response calendar established
- [ ] Go / no-go decision recorded

This public worksheet is a preparation aid. It does not determine eligibility, qualification, or award probability and does not submit an RFx response.
